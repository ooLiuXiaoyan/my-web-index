Hermes — 开源本地优先 AI 智能体框架

由 Nous Research 开发，支持多模型接入、工具调用、自定义技能，覆盖从原型验证到企业级部署的全场景需求

核心能力一览

🧠 多模型接入

支持 OpenAI、Anthropic、DeepSeek、本地 Ollama 等 20+ 模型提供商，按需切换。

🔧 工具调用

内置文件读写、Shell 执行、HTTP 请求、数据库查询等工具，支持自定义工具扩展。

🎯 自定义技能

通过 Skill 系统封装领域知识，一键安装社区技能，快速构建专属工作流。

💾 记忆系统

短期对话缓存 + 长期持久记忆，跨会话保持上下文，知识持续积累。

🔌 MCP 协议

原生支持 Model Context Protocol，无缝对接第三方 MCP 服务器和工具生态。

🔐 安全可控

代码本地执行，数据不出境；权限分级管理，敏感操作需确认，合规无忧。

🌍 行业实战场景

以下场景基于 Hermes 核心能力，结合地理信息研发、人工智能、数据治理、企业出海、工业互联网五大领域的典型需求展开。

🗺️

地理信息研发（GIS）

空间数据处理 · 地图服务开发 · 遥感分析

场景一：空间数据 ETL 自动化

地理信息研发中，数据来源多样（Shapefile、GeoJSON、遥感影像、矢量瓦片），格式转换与清洗是高频任务。Hermes 可通过自定义技能封装 GDAL/OGR 工具链，实现一键式数据转换。

# 通过 Hermes 批量转换 Shapefile 为 GeoJSON hermes chat -q "将 data/shapes/ 目录下所有 .shp 文件转为 GeoJSON，输出到 output/geojson/" # Hermes 会自动调用 GDAL 工具完成转换： # ogr2ogr -f GeoJSON output/file.geojson data/shapes/file.shp
  • 坐标系批量转换 — 将不同来源的空间数据统一到 WGS84 或 CGCS2000 坐标系
  • 遥感影像预处理 — 批量裁剪、波段合成、辐射校正脚本生成
  • 地理编码服务 — 地址文本转坐标，支持批量处理百万级地址

场景二：地图服务开发辅助

使用 Hermes 辅助开发 Mapbox GL / OpenLayers / Leaflet 前端代码，快速搭建 WebGIS 应用原型。

# 让 Hermes 生成一个基于 OpenLayers 的矢量瓦片查看器 hermes --skill webgis-dev --model deepseek-v3 > 生成一个 OpenLayers 3.16 的矢量瓦片地图应用， > 支持图层切换、要素点击查询、坐标显示功能
💡

最佳实践：将 Hermes 的记忆系统用于存储项目中的空间数据 Schema 和 API 规范，确保多轮对话中保持一致的上下文。

GIS开发 GDAL 遥感 空间分析 坐标转换

人工智能

模型开发 · Prompt 工程 · Agent 构建

场景一：模型评估与对比

AI 研发人员需要在多个模型之间快速切换，评估不同模型在特定任务上的表现。Hermes 的多模型接入能力使这一过程高效可控。

# 快速对比不同模型对同一任务的表现 hermes model # 交互式选择模型 # 使用 DeepSeek-V3 hermes chat --model deepseek/deepseek-chat --q "分析这段代码的性能瓶颈" # 切换到 Claude Sonnet 对比 hermes model anthropic/claude-sonnet-4-20250514 hermes chat --q "分析这段代码的性能瓶颈"
  • Prompt 模板管理 — 在记忆系统中存储经过验证的 Prompt 模板，跨会话复用
  • Agent 工作流设计 — 使用子代理编排复杂的多步骤 AI Pipeline
  • RAG 管道调试 — 通过文件工具读取文档片段，测试检索增强生成效果

场景二：代码生成与审查

Hermes 可作为 AI 辅助编程助手，在项目目录中读取代码上下文，生成符合项目风格的新代码。

# 在项目目录中启动 Hermes，自动加载项目上下文 hermes --workspace ./my-project > 为 src/services/ 目录下的 API 模块编写单元测试， > 使用 pytest，覆盖正常路径和边界情况
⚠️

注意：AI 生成的代码需经过人工审查。Hermes 的工具调用权限分级机制可确保敏感操作（如 git push）需用户确认。

模型评估 Prompt工程 Agent编排 代码生成 RAG

数据治理

数据质量 · 元数据管理 · 合规审查

场景一：数据质量自动检测

数据治理的核心挑战之一是数据质量。Hermes 可通过自定义技能封装数据质量检测规则，对数据集进行自动扫描并生成质量报告。

# 使用 Hermes 扫描 CSV 数据集质量 hermes chat --skill data-quality > 分析 data/customers.csv 的数据质量： > 1. 检查空值比例 > 2. 识别重复记录 > 3. 验证字段格式（邮箱、手机号、身份证） > 4. 生成质量报告到 reports/ 目录
  • Schema 一致性校验 — 自动比对数据库 Schema 与文档定义，发现漂移
  • 敏感数据扫描 — 识别数据集中的 PII 信息（姓名、手机号、身份证号）
  • 数据血缘追踪 — 分析 ETL 脚本，自动生成数据流向图

场景二：元数据管理自动化

通过 Hermes 与数据库工具的集成，自动提取表结构、字段描述、数据类型等元数据，生成数据字典。

# 通过 MCP 连接 PostgreSQL 数据库 # 在 ~/.hermes/.env 中配置 MCP_SERVERS=postgres@localhost:5432/mydb # 让 Hermes 生成数据字典 hermes --mcp postgres > 连接数据库，提取所有表的元数据， > 生成 Markdown 格式的数据字典到 docs/data-dict.md
💡

合规提示：在处理敏感数据时，建议使用本地模型（如 Ollama 运行的 Qwen/Llama）以确保数据不出境。Hermes 原生支持本地模型接入。

数据质量 元数据 合规审查 数据字典 PII检测

企业出海

多语言处理 · 本地化 · 跨境合规

场景一：多语言内容本地化

企业出海面临的首要挑战是语言。Hermes 支持多语言 Prompt，可批量完成产品文案、帮助文档、营销素材的翻译与本地化。

# 批量翻译产品文案为多语言版本 hermes chat --model deepseek-v3 > 将 docs/product-intro.md 翻译为英语、日语、韩语、西班牙语， > 保持技术术语一致性，输出到 docs/translations/ 目录下 > 每个语言版本保留对应的文件名后缀（_en, _ja, _ko, _es）
  • UI 文案国际化 — 批量提取代码中的硬编码字符串，生成 i18n 资源文件
  • 本地化适配建议 — 分析目标市场文化差异，提供 UI/UX 本地化建议
  • 多语言客服知识库 — 构建多语言 FAQ，支持跨语言语义检索

场景二：跨境合规文档生成

不同国家/地区的数据保护法规差异巨大（GDPR、CCPA、PIPL）。Hermes 可辅助生成合规文档模板。

# 生成 GDPR 合规隐私政策模板 hermes chat > 根据我们产品的功能（用户注册、数据收集、第三方分析）， > 生成符合 GDPR 要求的隐私政策文档模板， > 包含数据收集说明、用户权利、数据保留政策等关键条款
⚠️

重要提醒：AI 生成的合规文档仅供参考，必须经过法律专业人士审核后方可使用。Hermes 适合作为起草工具，而非最终合规方案。

多语言 本地化 GDPR i18n 跨境合规

工业互联网

设备监控 · 预测性维护 · 产线优化

场景一：设备日志分析与故障诊断

工业设备产生的日志量巨大，人工排查效率低。Hermes 可通过文件工具批量读取日志，结合模型能力进行智能诊断。

# 分析设备运行日志中的异常模式 hermes chat --model deepseek-v3 > 读取 logs/ 目录下最近 7 天的设备运行日志， > 识别异常模式： > 1. 温度超限事件 > 2. 振动频率异常 > 3. 通信超时 > 4. 能耗突变 > 输出异常报告到 reports/device-analysis.md
  • 预测性维护 — 基于历史数据模式，预测设备故障窗口期
  • OPC UA 数据解读 — 解析 OPC UA 协议数据，生成可读的设备状态报告
  • 产线效率分析 — 分析 OEE（设备综合效率）数据，识别瓶颈环节

场景二：工业文档智能检索

工业企业的设备手册、操作规程、维修记录通常分散在多个系统中。Hermes 的文件工具和记忆系统可用于构建智能文档助手。

# 构建设备知识库问答系统 hermes --skill industrial-docs --memory long-term > 将 docs/manuals/ 目录下所有设备手册加载到长期记忆中， > 之后可以快速查询："CNC 数控机床 X 轴报警 E07 的处理步骤是什么？"
💡

部署建议：工业场景对实时性要求高，建议将 Hermes 部署在边缘计算节点上，使用本地模型（如 Qwen-7B）以降低延迟。Hermes 支持 Ollama 本地部署。

设备监控 预测性维护 OPC UA OEE分析 边缘部署
