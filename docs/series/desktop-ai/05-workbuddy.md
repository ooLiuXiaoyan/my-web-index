# WorkBuddy 深度体验：腾讯的桌面 Agent 之路

<span class="badge badge-done">已发布</span> <span class="badge badge-wip">定期刷新</span>

> 📅 信息截至 2026 年 11 月。本文基于新华社、财新等公开报道与官方资料整理，实操细节以官方最新版本为准。

在国产桌面 Agent 里，WorkBuddy（昵称「小龙虾」）是最值得单独写一篇的产品——不只因为它是腾讯出品，更因为它走通了一条与众不同的路：**用 IM 生态做 Agent 的分发和交互入口**。

## 产品定位

- 2026 年 3 月 9 日发布，定位「AI 原生桌面智能体工作台」，是腾讯办公智能体的主力产品
- 与字节「豆包工作」、阿里「千问办公」同赛道竞争
- 发布之初就旗帜鲜明地对标 OpenClaw：**完全兼容 OpenClaw 技能包**，同时把开源框架「需要折腾部署」的门槛打到「1 分钟下载安装连上企业微信」

这个定位很腾讯：不拼模型参数的叙事，拼**连接**——连接微信、企业微信、QQ、邮箱，连接你已经沉淀在腾讯系产品里的全部工作上下文。

## 看点一：OpenClaw 技能兼容

如果你读过本站的 [OpenClaw 实战系列](../openclaw/)，这一条会直接命中你：

- 在 OpenClaw 社区积累的技能包，可以无缝迁移到 WorkBuddy
- 对开发者：此前写的技能资产不浪费，还白捡一个免部署的运行环境
- 对普通用户：零代码导入技能，或直接用内置的 20+ 技能包

**兼容的边界**：技能里涉及自定义模型接入、私有 Gateway 配置的部分，迁移时需要按 WorkBuddy 的模型与权限体系重新适配——技能逻辑能带走，基础设施换了一套。

## 看点二：微信远程遥控

2026 年 3 月版本更新的杀手级功能：

1. 在设置里绑定微信客服号
2. 出门后，在微信里发一条语音或文字
3. 办公电脑上的 WorkBuddy 立刻开工：查资料、写文案、处理报表
4. 全程在本地运行，结果直接推回你的微信

**只要电脑不关机，它就是 7×24 小时的随身助理。**「急着交材料又不在办公室」这个场景，被它打得非常准。除了微信，还支持通过企业微信、QQ、飞书、钉钉发指令遥控。

## 看点三：企业微信双向联合

2026 年 10 月 14 日，企业微信与 WorkBuddy 发布联合新版本，这是它今年最重要的一步棋：

- **WorkBuddy 进入企微通讯录**：以可对话机器人的身份出现在联系人列表，聊天即下达任务
- **共用一套账号体系**：WorkBuddy 5.8.0 支持企微账号登录，在企业授权范围内获得**消息、文档、会议、微盘等十项能力权限**
- **企业级管控**：管理员可以统一配置机器人、分配账号、管理用量与算力采购，按组织身份设置访问权限，限制 AI 访问高敏感信息

背景的含金量：企业微信覆盖超过 1400 万真实企业与组织，每天通过企微服务的微信用户达 7.5 亿。WorkBuddy 一夜间拿到了别人烧多少钱都买不到的入场券。而且企微能直连 C 端微信，这意味着 Agent 不只能处理内部办公，还能承接对外的销售与客服场景——这是飞书、钉钉都不具备的独特链路。

## 技术栈

| 层 | 情况 |
| --- | --- |
| 模型 | 多模型开放：混元 Hy4（2026 年 11 月发布，原生支持 Computer Use，幻觉率从 12.95% 降至 7.2%）、DeepSeek、GLM、Kimi、MiniMax |
| 扩展 | 支持 MCP 协议，20+ 内置技能包，兼容 OpenClaw 技能 |
| 执行 | 本地运行为主，多窗口、多 Agent 并行拆解复杂任务 |
| 自动化 | 定时任务（如「每天早 9 点抓行业热点」「每周五整理会议纪要」），企微断网自动重连 |

一个值得注意的数据飞轮：用户提交的任务 prompt 质量很高，在不涉及隐私的前提下会回授给混元做后训练——**办公场景的数据闭环正在反哺模型**。

## 适合谁、不适合谁

**适合**：

- 企业在用企业微信的团队——零迁移成本，开箱即用
- 重度微信用户想要「手机遥控电脑」的个人
- 有 OpenClaw 技能积累、想要免部署环境的开发者

**不适合**：

- 工作流完全不在腾讯生态内的团队（生态红利吃不到，就只剩一个普通桌面 Agent）
- 对「数据回授训练」敏感的场景——需仔细评估企业版的数据管控条款（详见第 07 篇）

## 小结

WorkBuddy 的打法给这个品类提供了一个重要样本：**桌面 Agent 的竞争下半场，可能不是模型之争，而是入口与上下文之争**。谁能合法、顺畅地拿到你的工作上下文（聊天、文档、会议），谁的 Agent 就更能干。
