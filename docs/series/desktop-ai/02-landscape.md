# 主流产品全景横评：2026 年的桌面 AI 助手怎么选

<span class="badge badge-done">已发布</span> <span class="badge badge-wip">定期刷新</span>

> 📅 **数据截至 2026 年 11 月**。这个品类迭代极快，价格与功能以各官网最新信息为准；本文配合站点的更新提醒工作流定期刷新。

上一篇把桌面 AI 助手分成了三种形态，这篇回答最实际的问题：**现在市面上这些产品，各自处于哪个形态、适合什么人？**

## 横评维度

四把尺子量到底：

| 维度 | 看什么 |
| --- | --- |
| **云端 vs 本地** | 模型在哪跑、数据存哪、能否离线 |
| **对话 vs 执行** | 能否读写本地文件、操作软件、跑定时任务 |
| **生态绑定** | 和 IM / Office 套件的打通深度 |
| **价格** | 免费额度与付费门槛 |

## 国际产品

### ChatGPT 桌面端 / ChatGPT Work

OpenAI 把 Operator 折进了 ChatGPT，2026 年中长成 ChatGPT Work：给它一个任务（如「订周五下午 3 点后最便宜的直飞航班」），它打开云端浏览器一步步操作，关键节点停下来等你确认。桌面端现在也能操作你自己的电脑。

- **优势**：生态最全（日历、Slack、Gmail 连接器），Web 类任务最稳，Go 套餐 $8/月起门槛最低
- **短板**：模糊目标容易失败，Computer Use 能力晚于 Claude

### Claude 桌面端 / Cowork

Anthropic 的路线偏「文件与文档」：Cowork 面向知识工作，能直接处理本地文件；computer use 通过 API 开放，Claude in Chrome 则是浏览器侧的轻量形态。

- **优势**：长文档处理与写作质量公认最强，computer use 起步最早、最成熟
- **短板**：操作真实环境的风险需要沙箱意识，无图像生成能力

### Microsoft Copilot

分两层：Windows 任务栏里的 Copilot 是「系统级辅助」形态的代表；Copilot Studio 的 computer use（含 Windows 365 Cloud PCs）面向企业无人值守自动化。

- **优势**：M365 组织内无缝（Word / Outlook / Teams 上下文），企业管控能力最完整
- **短板**：强绑定微软生态，个人用户体验平庸

### Gemini 桌面端

Google 2026 年 9 月推出 Windows 桌面端，Alt + Space 唤起，主打 Google Workspace 用户。

- **优势**：价格激进（入门档约 $4.99/月），Workspace 集成顺滑
- **短板**：桌面端功能仍在追赶，部分 macOS 特性未到 Windows

## 国内产品

### Kimi Work

月之暗面的桌面端 Agent：读写本地文件、本地跑命令、浏览器自动化（WebBridge）、定时任务，数据留在设备本地。在 SuperCLUE 2026 年 10 月的 Office Agent 测评中综合排名靠前，数据分析与材料撰写两个维度领先。

- **优势**：长文档 / 多 PDF / 调研报告场景突出，本地优先的隐私姿态
- **适合**：研究、咨询、内容创作类知识工作者

### 豆包电脑版

字节的桌面助手：划词交互、联网搜索之外，电脑版独占「工作任务模式」（授权后操作本地电脑）、Office 本地集成和定时任务。与飞书同生态原生打通，权限直接继承。

- **优势**：免费额度友好，中文场景与飞书生态顺滑，功能铺得最广
- **短板**：深度执行能力在复杂任务上波动较大

### 腾讯 WorkBuddy

腾讯 2026 年 3 月推出的 AI 原生桌面智能体工作台：兼容 OpenClaw 技能包、支持 MCP、微信远程遥控、10 月与企业微信双向联合。看点太多，**单列第 05 篇专篇详写**，这里先占位。

### 阿里千问办公

阿里在同赛道的应答，与钉钉生态绑定。目前公开信息相对少，本文持续跟踪，待有明确产品形态后补充。

### 办公套件内嵌 AI：WPS AI / 钉钉 AI / 飞书 AI

严格说它们不是独立桌面助手，而是 AI 长在了办公软件里：WPS AI 做文档润色与 PDF，钉钉 AI 做会议纪要与待办，飞书则接入豆包能力起草周报。

- **定位**：如果你的工作 80% 发生在某个套件内，内嵌 AI 的摩擦最小；跨软件任务则需要独立桌面 Agent

| 产品 | 形态 | 本地文件 | 定时任务 | 生态绑定 | 付费门槛 |

| Gemini 桌面端 | 辅助为主 | 部分 | ❌ | Google Workspace | $4.99/月起 |
| Kimi Work | 对话 + 执行 | ✅ | ✅ | 弱（通用路线） | 以官网为准 |

## 选型建议矩阵

| 你是谁 | 首选建议 |
| --- | --- |
| 个人效率用户，预算敏感 | 豆包电脑版 / Gemini 入门档起步 |
| 深度文档与调研工作者 | Kimi Work 或 Claude Cowork |
| M365 企业用户 | Microsoft Copilot（组织统一部署） |
| 微信 / 企微生态团队 | WorkBuddy（见第 05 篇） |
| 飞书生态团队 | 豆包电脑版 + 飞书 AI |
| 开发者 / 极客 | 看完第 08 篇，考虑自建工作流 |

## 总结

2026 年的桌面 AI 助手没有「全能冠军」，只有「场景最优」：**Web 任务看 ChatGPT Work，文档深度看 Claude / Kimi，生态效率看各家 IM 绑定款**。下一篇我们把对比再推进一层：不看产品看能力，拆解桌面 Agent 的四大件。
