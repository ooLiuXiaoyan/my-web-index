# Google / DeepMind 产品图谱

<span class="badge badge-done">已发布</span>

Google / DeepMind 的产品生态覆盖 Gemini 4、Gemma、消费应用、开发者工具、企业办公、Agent、云计算、自研硬件与科学研究。资料核对日期：**2026-11-23**；研究原型、正式产品和各地区可用功能在条目中分别说明。

> 🧠 **8** 大产品分类 ｜ 📦 **50+** 产品与研究方向 ｜ 🏆 **1** 项诺贝尔化学奖 ｜ 🌍 覆盖消费者、开发者与企业

## 全景概览

Google / DeepMind 由 Google Brain 与 DeepMind 于 2023 年合并而成，由 Demis Hassabis 领导。

- **基础研究**：Transformer、AlphaGo / AlphaZero、AlphaFold 等长期研究积累
- **当前模型**：Gemini 4、Gemma 4，以及图像、视频、音频和世界模型
- **AI Agent**：Antigravity、Jules、Gemini Agent Mode，以及 Astra、Mariner 等研究项目
- **基础设施**：Cloud TPU、Vertex AI、Gemini API 与 Firebase 开发工具链
- **科学突破**：AlphaFold 相关研究获 2024 年诺贝尔化学奖，GNoME 和气候模型持续推进

## 📜 典型案例与里程碑

| 年份 | 事件 |
| --- | --- |
| 2016 | **AlphaGo 战胜李世石** — 以 4:1 战胜围棋世界冠军，成为深度强化学习的重要公众里程碑 |
| 2017 | **Transformer 论文** — Google 研究人员发表《Attention Is All You Need》，提出 Transformer 架构 |
| 2020 | **AlphaFold 2 突破** — 在 CASP14 中实现蛋白质结构预测的重要精度突破 |
| 2022 | **PaLM 大模型** — 发布 5400 亿参数语言模型，推动大规模语言模型研究 |
| 2023 | **Gemini 发布** — 发布原生多模态 Gemini 模型系列 |
| 2024 | **Agent 研究项目** — 展示 Project Astra 与 Project Mariner；Jules 属于后续发布的编程 Agent |
| 2024 | **诺贝尔化学奖** — Demis Hassabis 与 John Jumper 因蛋白质结构预测研究共同获得诺贝尔化学奖 |
| 2025 | **Gemini 3 与 Jules GA** — Gemini 3 系列发布，Jules 从测试阶段转为正式产品 |
| 2026 | **Gemini 4、Gemma 4 与 Genie 4** — Gemini 4 系列陆续发布，Gemma 4 面向推理与 Agent 工作流，Genie 4 推进可交互世界模拟 |
