# 飞书妙搭一键部署 OpenClaw 🦞

<span class="badge badge-done">已发布</span>

飞书妙搭是飞书在 2025 年 7 月推出的企业级 AI 应用搭建工具。2026 年 3 月，妙搭上线 OpenClaw（小龙虾）一键云部署功能，用户无需自行购买服务器或配置 Webhook，即可创建飞书内的 OpenClaw 应用。

> 📅 资料核对日期：2026-11-23。模型、额度和计费规则可能继续调整，请以实例页面及飞书官方说明为准。

## 依赖的模型是什么？

飞书托管实例会使用平台配置的模型服务。根据当前官方计费说明，飞书 OpenClaw 也支持成员切换为企业自建部署模型或自行购买的第三方模型服务，因此不能再简单描述为「固定使用豆包」或「无法选择模型」。具体默认可用型号以创建实例时的配置页面为准。

| 部署方式 | 模型配置 | API Key 要求 |
| --- | --- | --- |
| 飞书妙搭托管模型 | 使用平台提供的模型服务，实际型号以实例配置为准 | 使用托管模型时无需自行申请 |
| 飞书妙搭 + 自建 / 第三方模型 | 由成员在支持范围内切换 | 按所选模型服务要求配置 |
| 阿里云自行部署 | 可在百炼可用列表中自行选择，例如 qwen3.5-plus | 通常需从阿里云百炼获取 |

## 服务器与当前费用

OpenClaw 运行在飞书云端托管环境中，用户无需自行购买或维护服务器。飞书未公开实例的具体 CPU、内存规格，因此本文不再根据其他云平台配置推断其性能，也不默认承诺自动弹性伸缩。

::: warning ⚠️ 免费活动已结束
2026 年 3 月的免费活动已结束。当前官方规则显示，费用由实际使用的模型、工具、产物和资源构成；处于开机状态的每个飞书 OpenClaw 应用**每日消耗 20 点额度**，关机、禁用或删除后按官方规则停止后续资源计费。使用企业自建或第三方模型时，平台模型费用为 0，但其他适用费用仍可能产生。
:::

详细规则请查阅[飞书 AI 版本权益与额度消耗规则](https://www.feishu.cn/hc/zh-CN/articles/629644238181-%E9%A3%9E%E4%B9%A6-ai-%E5%8A%9F%E8%83%BD%E4%BB%98%E8%B4%B9%E6%9D%83%E7%9B%8A%E8%AF%B4%E6%98%8E)。

## 飞书 aily 是什么？

飞书 aily 是面向企业的 Agent 平台，围绕大语言模型提供技能编排、知识数据处理、效果调优与持续运营能力。

- **aily 工作助手**：面向企业成员的通用智能体，可拆解并执行资料分析、网络信息整理、周报生成等任务，并按权限交付云文档、可视化报告、多维表格等成果
- **智能体开发平台**：面向开发者和业务专家，支持自定义企业智能体与工作流应用。可配置人设指令、接入企业知识，并通过 MCP 等方式连接业务系统

飞书 aily 与飞书协同生态集成，可在企业权限范围内使用文档、会议纪要、多维表格等数据。实际可用能力取决于企业版本、权限和当前产品配置。

## 飞书机器人类型区分

### 1. 自定义机器人

- **开发方式**：在群聊的机器人设置中添加，无需编写代码
- **能力范围**：主要通过 Webhook 向指定群聊推送消息，不是完整的双向对话应用
- **适用场景**：系统告警、定时通知等简单场景

### 2. 企业自建应用机器人

- **开发方式**：在飞书开放平台创建应用，开启机器人能力，并配置事件、权限和回调
- **能力范围**：可按授权调用 OpenAPI、订阅事件，支持单聊和群聊交互
- **适用场景**：业务系统集成、AI 助手和双向自动化流程

### 3. 飞书官方智能助手

由飞书官方提供，具体名称、任务能力和扩展方式随产品版本变化，应以企业内实际入口和官方说明为准。

### 4. 飞书妙搭部署的 OpenClaw

由妙搭完成云端实例和飞书接入配置，用户通过机器人形式与 OpenClaw 交互。它保留 OpenClaw 的任务执行和工具能力，并可按授权使用飞书生态能力，但不等同于自己维护的完整 OpenClaw 环境。

## 总结对比

| 对比项 | 飞书妙搭 OpenClaw | 飞书 aily | 自建应用机器人 |
| --- | --- | --- | --- |
| 底层模型 | 平台托管模型，也可按支持范围接入自建 / 第三方模型 | 由平台与企业配置决定 | 由开发者自行接入 |
| 服务器 | 飞书云端托管 | 飞书云端托管 | 用户自行购买和维护 |
| 部署难度 | 一键创建，后续按需配置模型和技能 | 按企业版本和场景配置 | 需创建应用、配置事件并开发服务 |
| 能力边界 | OpenClaw 工具执行与飞书集成 | 企业 Agent 编排、知识和工作流 | 取决于开发投入与授权范围 |
| 成本 | 按模型、工具、产物和资源等实际用量消耗额度 | 按企业版本及用量规则计费 | 模型、服务器和开发运维成本 |
| 适用人群 | 希望快速使用托管 OpenClaw 的个人和团队 | 需要企业 Agent 平台的组织 | 需要完全自定义且有研发运维能力的团队 |

::: tip 一句话总结
妙搭 OpenClaw 适合快速获得托管智能体；aily 适合企业 Agent 建设；自建应用机器人自由度最高，同时需要承担完整的研发和运维工作。
:::
